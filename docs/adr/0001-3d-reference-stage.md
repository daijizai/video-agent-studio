# ADR 0001：以统一3D场景提供跨镜参考

状态：**用户初步认可方向，待验证，暂不实施。** 这不是效果验证，也不是创建模型、接入Blender、安装依赖或新增费用的授权。本轮管线保持不变。

## 问题与理由

跨镜一致性不仅是人物身份，还包括道具外观不变、物件位置和持有人合理、移动动作有交代，以及可见/画外状态可解释。托盘变形与无解释消失属于不同问题，不能靠“画面是单幅”判定合格。

统一3D房间可固定空间几何、门窗、柜台、道具、人物相对位置与相机，作为跨镜头共同的空间底稿，减少每镜从文字重新发明背景的机会。

## 候选流程

1. 一个统一的简化3D房间与少量道具。
2. 设置人物位置/姿态和每镜相机。
3. 输出各镜头参考图；只有在目标模型明确支持时，才考虑深度、法线、遮罩等控制输入。
4. 用AI生成外观、材质或影像表现。
5. 检查门窗柜台位置、人物关系、道具外观与跨镜空间状态。

## 边界与待验证项

普通RGB参考图不是硬约束，AI仍可能改变家具、材质或小道具。不能把3D参考存在等同于模型严格遵守几何。深度/法线/遮罩支持必须按实际供应商API和模型逐项核对，不能猜测字段，也不能将普通参考图宣称为已接通的控制网络。

将来可用一个简单房间、少量机位做小试验，无需精细建模。比较原始参考与AI结果中的空间/道具偏差，再决定是否投入。具体试验范围、费用、依赖与验收另行确认；本次仅记录。
