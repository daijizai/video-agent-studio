# 后续角色资产规范（Backlog，本轮不生成）

用户已明确本次Demo先不扩充这些资产；以下只是后续项目设计，不产生额外生成次数或费用。

## 建议的角色母版

- 标准头像；头部正面、侧面、背面，可补三分之四脸。
- 完整全身，以及全身正面、侧面、背面。
- 同一人物身份、服装、发型、身材比例与可比较灯光，不把不同人物拼成“同一角色”资产。
- 每个视角保存独立图片与标签（角色ID、视角、版本、来源任务、批准状态）。人工批准后指定母版，后续镜头引用明确版本。
- 拼版仅作审阅展示，不直接将多格设定表作为镜头关键帧参考；避免模型复制多联版式。
- 角色母版/场景资产与具体镜头关键帧分开管理。某个镜头宽景可临时提供参考，但不能冒充完整角色三视图或全身设定。

未来验收：可查每个视角原图、供应商任务及成本、修改版本、人工批准母版；不在本轮新增生成或自动购买额度。
