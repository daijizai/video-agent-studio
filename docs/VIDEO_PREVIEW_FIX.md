# 整片默认预览修复

原因为：第05页默认取第一镜；整片任务与单镜shot_id不同，已有final_video仍会落到“单镜无结果”空态。

修复：没有用户显式选择时优先整片/整片任务；保留用户选择和播放中的媒体节点、进度与音量。用户选中没有独立视频的镜头时，明确提示已有整片可播放，并提供切换入口。相同整片再次查询不能重置用户阶段性接受记录。

真实本机验证：页面默认选择final，video.currentSrc指向已有本地MP4；Range请求返回206与video/mp4；原生controls可用，seek到10秒后播放/暂停，再更新面板进度未重置。测试期间没有生成请求。源文件不变，未重新生成媒体。

首版“阶段性接受”与所有对白、声线或道具客观完美不是同一概念；记录用户接受来源和保留限制。暂停新生成不移除预算或已交付文件。
