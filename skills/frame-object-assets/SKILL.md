# 物品资产

Codex 从故事和用户意图补足物品外观与内部提示。物品身份与剧情中的数量、位置、持有人分开。用 [物品交接模板](templates/object.md)，执行前读 [公共交接合同](../../docs/PRODUCTION_HANDOFF.md)。

## 选择与设计

先选推动剧情、频繁出现、需要特写或与人物交互的物品，不把每件背景杂物都升级成需要生成的独立资产。

设计包括用途、轮廓、结构连接、材料/表面、比例、颜色、开合/可动部件、少量辨识特征。区分剧本事实、系统创作选择和未知，用户已授权设计时不逐字段反问。

- 钥匙、笔、工具：主体完整，齿口、握柄或连接部位固定；必要时补侧面或局部。
- 托盘、盒、按钮：固定轮廓、边沿、底座和可动结构；不把所有剧情内容物生成成物品本体。
- 纸张、合同、屏幕：固定比例、版式和签字区域，精准可读内容单独排版检查。
- 对称物或无叙事意义的背面：可不生成冗余视图，按项目说明取舍。

## 主图与独立视图

先审阅采用单体主图，再引用明确原图和设计版本补必要正侧背/细节。不默认每件做满三视图，不一次生成三联画冒充三张原图；拼版仅审阅展示。

主图展示一个完整主体，无持有人、无剧情动作、少遮挡、简洁背景与可比较光照。角度为说明结构服务，不为“电影感”隐藏关键部件。

扩展视图保持结构、材料、颜色、连接方式与磨损分布，只改变观察角度或局部范围。尺度、主体占比和光线应可比较；弱透视目标不等于工程投影或真实几何。

生成前交接本次视图、候选数、母版依赖及总费用。没有合格参考时先补缺口，不能静默丢参考后声称同一外观。

## 提示与模型边界

按“单一物品与设计 → 当前视图 → 构图/光线/背景 → 保持项 → 必要排除项”组装，只选本图需要的信息。不把整集对白、拿取过程或剧情数量混进主图。

不虚构模型字段、硬控制或几何保证。生成出相似图不等于精确尺寸、色值或文字已验证。额外图、重做和输入参考按实际计费，不假定免费。

## 镜头道具状态

外观图中的一个单体用于定义设计；剧情要一个还是多个由镜头决定。位置、左右手、持有人、开合、可见/画外独立记录。移动一把钥匙不是重新设计一把钥匙。

上下镜变化须有拿取、放下、交接、移动或时间跳跃等依据。外形变化和无解释消失分别记；画外看不见不等于不存在，也不强迫每镜都露出。

## 验收、版本与入库

检查实际图片的完整边界、单体数量、结构、材质、视图和与采用主图的差异。可解码与视觉语义合格分开；没有观察依据就写未验。

精确文字要核对最终排版/文件，不能把提示词里的正确文字抄成实测结果。

原图关联资产与设计版本、视图、来源任务、模型、输入参考及文件摘要。人工采用后供新镜头选用，未采用候选和历史保留；新图不静默替换旧镜头参考。更改结构/材质生成新设计版本；只是不同位置/持有人不需新建外观资产。

用户看到名称、简要设计、图、版本、费用和反馈，不填机器prompt。模板完整不等于图片已合格，也不代替审批与执行授权。
