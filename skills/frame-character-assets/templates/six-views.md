# 人物标准视图交付

对具有头部和身体的角色，默认准备六个独立视图：头部正面、右侧、背面，以及全身正面、右侧、背面。头像母版若清楚满足头部正面的要求，可作为头部正面使用，不必为了改标签重复生成。

先计划身份母版，再采用全身结构基准，最后依据已采用原图生成其余视图；默认准备计划不等于自动提交六次生成。各图分开保存、逐张审阅，拼版仅用于审阅展示。

同一人物保持身份结构、服装/机体、材料和可辨识标记；背景、光线、姿态和主体尺度可比较。侧面明确主体右侧，背面不转头露正脸；全身保留实际存在的头、足、手或操作部件，不裁切。

机器人依真实结构填写，不添加人类发型、肤色；没有头或足的非人主体按其真实结构适配，不凭表格虚构部位。静态多角度图不保证严格三维几何或视频逐帧一致。
