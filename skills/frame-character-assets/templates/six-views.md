# 人物标准视图交付

对具有完整身体的角色，默认先准备全身正面、右侧、背面三个独立视图。优先以已采用的对应全身图裁取头部；先检查裁切后实际像素、清晰度和镜头需求，放大不会创造可靠细节。只有裁图不足以满足镜头时，才按需要准备相应头部视图，并以同方向已采用全身图为结构依据，比较外壳、头发、接缝等细节。保存原图、裁切区域和来源版本；独立生成可能改变身份或结构，须重新审阅。没有实现裁切的系统应如实提示，不得声称已自动裁切。

新角色默认先设计和审阅全身正面母版，再参考正面制作侧面；侧面经审阅采用后，背面同时参考已采用的正面与侧面，逐项对照机体与服饰结构。保留已有头像母版和历史引用，不自动替换；旧项目若以头像为身份母版，继续使用其已确认身份并补全身。计划不等于自动提交生成。各图分开保存、逐张审阅，拼版仅用于审阅展示。

同一人物保持身份结构、服装/机体、材料和可辨识标记；背景、光线、姿态和主体尺度可比较。侧面明确主体右侧，背面不转头露正脸；全身保留实际存在的头、足、手或操作部件，不裁切。

机器人依真实结构填写，不添加人类发型、肤色；没有头或足的非人主体按其真实结构适配，不凭表格虚构部位。静态多角度图不保证严格三维几何或视频逐帧一致。
