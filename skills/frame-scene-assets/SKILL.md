# 场景资产

根据已知故事和用户偏好，定义可拍、可复用的空间。按需使用 [场景交接模板](templates/scene.md)；涉及视频时同时读取项目视频提示词规范。

先区分已确认的故事事实、设计候选和未知项。定义固定的入口、主要家具、窗户、光源及它们的相对位置，记录地面、墙面、关键材料和尺度关系；区分会随剧情移动的道具、人物与不应改变的建筑结构。不要假设场景参考图严格锁定几何或相机位置。

场景母版展示可理解的空间，不含人物，参考图用于场景结构和质感，不作为视频首帧。镜头可改变景别、视角、虚化和合理光照；不要照搬参考图构图或要求每镜暴露全部家具。让主体、道具和动作可见，按故事选择构图。

先产生独立候选并保留原图、设计、来源和版本。由用户审阅采用后，片段才可以绑定具体版本；修改布局或替换图不能悄悄沿用旧审阅或覆盖历史请求。不得将待审阅图称为已采用或假称已经发送给模型。

遵循项目视觉风格与用户指定画幅；模型接口、参考数量、审批和费用由执行层核验。图片生成不等于视频生成授权，生成结果需要人工比较空间连续性。
