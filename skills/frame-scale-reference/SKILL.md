# 比例参考

使用已审阅素材，按 [交接模板](templates/reference.md) 记录主体与版本、同一深度时的相对尺度、环境参照、镜头视角和图像来源。比例描述应以用户确认的画面为依据；无法从单张二维图可靠测量的具体尺寸保留为未知，不冒充实测。

一张比例图可以包含多个明确主体。用户审阅采用后，可作为后续视频的比例参考；它不自动成为首帧，不要求复刻表情、站姿、道具状态或画面构图。主体身份仍由各自已审阅的素材负责，比例图与角色版本的关联应保留。

不同景别和深度可以导致正常透视变化；以同一深度的相对大小、场景参照和角色与地面的接触关系比较，避免用画面像素高度直接断言真实身高。生成结果必须再次审阅，不能承诺模型精确遵守。

保存候选、图像、来源、版本和用户审阅记录；角色版本改变时需重新核对引用。图像创作不代表已授权生成视频，审批、预算与调用由执行层处理。
